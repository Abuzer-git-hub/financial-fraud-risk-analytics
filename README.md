# Financial Fraud Detection & Risk Analytics

AI-powered Financial Fraud Detection System using Machine Learning, MySQL Data Warehouse, SQL Star Schema, and Power BI Analytics Dashboard.

---

## Project Overview

This project detects fraudulent financial transactions using Machine Learning and visualizes analytical insights using Power BI dashboards.

The project combines:
- Artificial Intelligence / Machine Learning
- Data Warehousing
- SQL
- Business Intelligence

into one complete analytics solution.

---

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Random Forest Classifier
- MySQL Workbench
- SQL
- Power BI
